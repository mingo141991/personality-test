# 人格小测微信小程序原型

这是一个轻量的人格、状态与职业兴趣探索小程序原型。

## 已实现

- 温柔治愈风格首页
- 首页测试中心结构，支持四类测试入口
- MBTI 风格人格测试，包含 48 道题、16 型人格基础结果和详细解析
- 情绪压力小测，包含 24 道题、四维压力状态和恢复建议
- 大五人格测试，包含 50 道题、五维特质画像和理解建议
- 职业兴趣探索，包含 36 道题、六维兴趣画像和探索建议
- 四类测试均为逐题答题流程
- E/I、S/N、T/F、J/P 四维计分
- 16 型人格基础结果
- 结果页原创人物视觉卡与 NT/NF/SJ/SP 分组代号
- 结果页四维倾向报告，解释每个维度的偏好含义和强度
- 结果页展示基础描述、详细维度、建议和完整解析；当前无广告模式下默认开放完整内容
- 激励视频广告能力已预留，但当前隐藏所有广告入口，后续拿到流量主后再开启
- 答题过程中临时保留当前进度
- 本地保存最近一次结果，支持回到首页后随时查看
- 本地历史记录列表，最多保留最近 20 次测试结果
- 结果与历史记录带 `testId`，为后续多测试类型扩展做兼容
- 结果页按 `testId` 分流，MBTI、大五人格、情绪压力小测和职业兴趣探索都有独立报告样式，其他测试类型保留通用兜底
- 首页、关于页、结果页基础转发入口
- 结果页支持分享给朋友和分享到朋友圈标题
- MBTI、大五人格、情绪压力小测和职业兴趣探索结果页支持本地生成分享图、预览并保存到相册
- 关于页与非诊断声明
- 关于页补充压力小测边界、本地存储、分享图和内容开放说明
- 当前不登录、不展示广告位；详细解析和包含细节的分享图默认开放

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：

```text
D:\mingo\小程序开发\personality-miniapp
```

4. AppID 可先选择测试号或使用游客模式。

## 版本控制与基线

- 本目录是一个独立的 git 仓库（分支 `main`），首次提交为“建立版本控制基线（QA 12/12 通过）”。
- 该提交就是**已知可用基线**：`node qa\functional-test.js` 12 项全部通过时的完整状态。
- 改坏了用 `git restore .`（未提交）或 `git reset --hard <提交号>`（已提交）回到基线；看改动差异用 `git diff`。
- `project.private.config.json`（开发者工具本地私有配置）已列入 `.gitignore`，不进版本库。

## 后续接入方向

- 后续拿到流量主后，可在 `config/ad.js` 中开启 `rewardedVideo.enabled` 并填写 `adUnitId`，再恢复激励视频解锁流程。
- 付费深度报告上线前增加微信登录和订单权益绑定。
- 接入云端同步、登录权益和更多轻量测试类型。

## 发布前检查

- 运行 `node qa\functional-test.js`，确认自动化功能回归全部通过。
- 测试细则见 `qa\functional-test-plan.md`，本轮测试报告见 `qa\test-report.md`。
- 在微信开发者工具中预览四类测试，确认基础结果、详细解析和分享图入口正常，且页面不展示广告解锁入口。
- 在真机预览中重点检查按钮宽度、分享图弹窗、历史筛选条和结果页长文案换行。
- 如后续接真实激励视频广告，先在 `config/ad.js` 填写 `adUnitId` 并开启 `rewardedVideo.enabled`，再回归未完整观看不解锁、完整观看后解锁。
- 如需分享图支持“长按识别小程序”，先把小程序码图片放入项目资源目录，再在 `config/poster.js` 开启 `miniProgramCode.enabled` 并填写 `imagePath`。
- 提交审核前检查关于页的非诊断声明、职业兴趣非筛选声明和隐私说明。
