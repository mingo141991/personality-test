# 人格小测（Personality Test）

一个温柔、克制、非诊断的微信小程序：用 MBTI 风格、大五人格、情绪压力和职业兴趣四类测试，帮助用户温和地了解自己。

> 所有结果均为"自我了解的观察"，不构成心理诊断、不用于招聘筛选。

## 功能

- **四类测试**，全部本地运行、无需登录、无后端：

| 测试 | 题量 | 大约时长 | 说明 |
| --- | --- | --- | --- |
| MBTI 风格人格测试 | 48 题 | 8 分钟 | 四维倾向、16 型人格、专业温和的建议 |
| 大五人格测试 | 50 题 | 8 分钟 | 五维特质画像与理解建议 |
| 情绪压力小测 | 24 题 | 4 分钟 | 压力指数、四维压力进度条、恢复建议 |
| 职业兴趣探索 | 36 题 | 6 分钟 | 六维兴趣画像与探索建议 |

- **逐题答题**：选完自动跳下一题，答题进度本地临时保留。
- **结果报告页**：不是只显示一个类型，而是像报告一样展示维度倾向、强度、解释与建议。
- **原创人物插画**：16 型 MBTI 及大五/压力/职业分享图的人物画像均为 WXML/CSS 或 canvas 绘制的原创角色，不使用网络图片，无版权风险、无文字徽章。
- **本地历史记录**：最多保留最近 20 条，可按测试类型筛选。
- **分享图**：四类结果均支持生成分享图、预览、保存到相册。
- **广告预留**：激励视频广告能力已接入但默认关闭，拿到流量主后可开启。

## 技术栈

- 原生微信小程序（无第三方框架、无 npm 运行时依赖）
- WXML + WXSS + JavaScript
- 本地存储（`wx.setStorageSync` / LRU 保留 20 条）
- Canvas 2D 绘制分享图

## 目录结构

```
personality-miniapp/
├── app.js / app.json / app.wxss   # 全局入口、配置、样式
├── pages/
│   ├── home/       # 首页：测试中心、最近结果
│   ├── quiz/       # 答题页（四类共用，按 testId 加载题库）
│   ├── result/     # 结果页（按 testId 分流四类报告 + 分享图）
│   ├── history/    # 历史记录（筛选 + 本地存储）
│   └── about/      # 关于页（含非诊断声明）
├── data/           # 题库、结果文案、维度、人物视觉配置
├── utils/          # 计分、报告、本地存储
├── services/       # 广告服务（预留）
├── config/         # 广告 / 分享图配置
└── qa/             # 自动化功能回归脚本与测试报告
```

## 快速开始

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择"导入项目"，项目目录选本仓库根目录。
3. AppID 可用**测试号**（`touristappid`）或你自己的小程序 AppID。

> 仓库里的 `project.config.json` 已把 AppID 设为 `touristappid`（游客模式占位）。
> 你自己的 AppID 写在 `.gitignore` 排除的 `project.private.config.json` 里，不会提交。

## 运行测试

无需微信开发者工具，用 Node.js 即可跑自动化回归（内置 wx/wx API mock）：

```bash
node qa/functional-test.js
```

覆盖：页面加载、四类题库与计分、答题流程、结果分流、分享规则、分享图绘制、存储迁移、历史筛选等，当前 13 项全部通过。测试细则见 `qa/functional-test-plan.md`。

## 配置

- **广告**：`config/ad.js` —— `rewardedVideo.enabled` 默认 `false`；接入流量主后填 `adUnitId` 并置 `true`。
- **分享图小程序码**：`config/poster.js` —— 默认关闭；开启后把小程序码图片放入资源目录并填 `imagePath`。
- **唤醒词 / 文案**：题库与文案在 `data/` 下，均为本地 JSON/JS，可直接编辑。
