# 人格小测功能测试细则

## 1. 测试目标

验证当前原型达到可发布上线的基本质量：

- 四类测试入口均可用：MBTI、大五人格、情绪压力、职业兴趣。
- 答题流程稳定：逐题作答、自动跳题、草稿恢复、重新开始、最终生成结果。
- 结果页统一规则正确：当前无广告发布态下，基础描述、详细解析和建议默认开放。
- 分享功能遵守当前无广告发布态：可以生成包含细节的分享图，不展示广告解锁入口。
- 首页、历史、结果页对四类 `testId` 均能正确展示。
- 本地存储兼容旧记录，并限制最多 20 条历史。
- 页面脚本无语法错误或缺失引用。
- 关键 UI 风险点不应出现横向溢出：按钮、历史筛选、分享弹窗、结果页维度报告。

## 2. 测试环境

- 项目目录：`D:\mingo\小程序开发\personality-miniapp`
- 自动化逻辑测试：Node.js + 模拟微信小程序运行时。
- 人工视觉测试：微信开发者工具模拟器和真机预览。
- 广告状态：默认 `rewardedVideo.enabled = false`，隐藏广告位和解锁入口；真实广告接入后需补充广告单元回归。

## 3. 功能测试范围

### 3.1 页面配置

- `app.json` 必须包含：
  - `pages/home/home`
  - `pages/quiz/quiz`
  - `pages/result/result`
  - `pages/history/history`
  - `pages/about/about`
- `lazyCodeLoading` 保持 `requiredComponents`。
- 所有页面脚本可加载，无语法错误。

### 3.2 首页

- 首页显示品牌、开始推荐测试、测试中心。
- 推荐测试应进入可用测试，默认优先进入带“推荐”标记的 MBTI。
- 四类测试卡均为可开始：
  - MBTI 风格人格测试，48 题。
  - 大五人格测试，50 题。
  - 情绪压力小测，24 题。
  - 职业兴趣探索，36 题。
- 点击每张可用测试卡，跳转到对应 `testId` 的答题页。
- 最近结果存在时：
  - “查看上次结果”按钮只显示该文案。
  - 最近结果卡展示中文测试名、基础结果标题、基础摘要、完整报告状态。
  - 点击最近结果进入结果页。
- 历史记录存在时，显示历史数量并可进入历史页。
- 最近结果不存在时，触发查看上次结果应提示“还没有上次结果”，不能跳转空结果页。
- 首页分享文案不能写死旧题数。

### 3.3 答题页

- 不传 `testId` 或传无效 `testId` 时默认进入 MBTI。
- 传入 `mbti`、`big-five`、`stress`、`career` 时，加载对应题库、题数、题型和选项。
- 题目显示：
  - MBTI 为 A/B 倾向选择。
  - 大五、压力、职业为量表题。
  - “第 X 题”显示正确。
  - 题目卡片高度稳定，长题目不应把选项区顶下去。
- 选择选项后：
  - 当前答案保存。
  - 非最后一题自动跳到下一题。
  - 自动跳题期间，上/下一题/重新开始不应打断状态。
- 未选择答案点击下一题，应提示“先选择一个答案吧”。
- 上一题可回看并保持已选答案。
- 重新开始清空当前测试草稿并回到第 1 题。
- 最后一题选择答案后点击“查看结果”，应生成对应测试结果、清空草稿、保存最近结果和历史记录，并进入结果页。

### 3.4 计分与报告

- MBTI：
  - 48 题参与计分。
  - 生成 16 型之一。
  - 生成四维倾向条。
  - 广告关闭时默认 `unlockedFullResult = true`。
- 大五：
  - 50 题参与计分。
  - 生成 5 个维度。
  - 生成最高维度和基础摘要。
  - 广告关闭时默认 `unlockedFullResult = true`。
- 压力：
  - 24 题参与计分。
  - 生成压力等级、压力指数、4 个压力维度。
  - 广告关闭时默认 `unlockedFullResult = true`。
- 职业：
  - 36 题参与计分。
  - 生成 6 个职业兴趣维度。
  - 生成最高维度、辅助维度和基础摘要。
  - 广告关闭时默认 `unlockedFullResult = true`。

### 3.5 结果页展示

- 四类结果在当前无广告发布态下展示基础结果描述和完整详细解析：
  - MBTI：类型、昵称、角色视觉、基础摘要。
  - 压力：压力指数、压力等级、基础摘要。
  - 大五：五维画像标题、最高维度提示、基础摘要。
  - 职业：职业兴趣标题、主要兴趣/辅助线索、基础摘要。
- 以下详细内容应直接显示：
  - MBTI 四维倾向、维度解读、个性化建议、完整详情。
  - 压力维度、恢复建议。
  - 大五五维画像、理解建议。
  - 职业兴趣维度、探索建议。
- 不应显示“详细解析”解锁卡或广告观看入口。
- 通用未知测试类型进入 generic 兜底，不显示解锁和分享细节入口。

### 3.6 广告隐藏与未来解锁

- 当前 `rewardedVideo.enabled = false` 时：
  - 新生成结果直接为 `unlockedFullResult = true`。
  - 结果页不显示解锁卡、广告弹窗或模拟倒计时。
  - 旧的未解锁记录进入结果页时应归一化为完整报告。
  - 首页和历史状态展示“完整报告”。
- 后续真实广告开启后再补充：
  - 关闭弹窗不会解锁。
  - 未完整观看真实广告时不应解锁。
  - 完整观看后解锁并同步最近结果和历史记录。

### 3.7 分享与分享图

- 当前无广告发布态：
  - 分享给朋友可使用完整结果文案。
  - 可以生成分享图。
  - 分享图可包含详细维度信息和建议摘要。
  - 分享图弹窗按钮竖排，不应超出容器。
  - 保存和预览入口可用。
- 后续真实广告开启后，未解锁状态必须回归拦截，不能从分享入口泄露细节。
- 四类测试均支持分享图绘制逻辑：
  - MBTI 角色头像。
  - 压力符号和压力维度。
  - 大五五维条形图。
  - 职业兴趣六维条形图。

### 3.8 历史记录

- 保存结果后，历史记录新增或更新。
- 最多保留最近 20 条。
- 旧记录缺失 `id`、`testId`、`savedAt` 时可迁移。
- 历史页展示中文测试名、结果标题、摘要、保存时间和状态。
- 历史筛选包含“全部”和已存在测试类型。
- 点击筛选后只展示对应测试类型。
- 点击历史记录进入结果页，并能保持基础/已解锁状态。
- 清空历史后，最近结果同步清空。

### 3.9 UI 与窄屏风险

- 页面不应横向溢出。
- 按钮不应超出容器。
- 分享结果区和分享图弹窗按钮必须竖排安全。
- 历史筛选条可以横向轻扫，不挤压列表。
- 结果页报告标题、徽章、建议块、维度含义格长文案可正常换行。
- 答题页题目长短不应导致选项区位置大幅跳动。

## 4. 回归测试规则

当发现问题并修改代码后，必须执行：

- 受影响功能的直接用例。
- 同类测试的横向回归，例如改结果页要回归四类结果。
- 当前无广告模式回归，确保不展示广告入口且完整内容可用；后续开启广告时再回归未解锁不能从分享入口泄露细节。
- 页面脚本加载检查。
- 若改动存储逻辑，必须回归旧记录迁移和最多 20 条限制。

## 5. 本轮自动化覆盖

自动化脚本覆盖：

- 页面脚本加载。
- 测试配置和题库数量一致。
- 四类计分结果生成。
- 结果页 view model 分流。
- 无广告完整分享规则；后续开启广告时补充未解锁/已解锁分享规则。
- 广告关闭时分享图生成入口可用，解锁卡受广告开关隐藏。
- 保留的解锁保存逻辑。
- 历史存储迁移、更新、上限。
- 首页/历史展示状态和筛选逻辑。

人工仍需补充：

- 微信开发者工具内真实 WXML/WXSS 渲染检查。
- 真机窄屏按钮、弹窗、分享图预览检查。
- 真实激励视频广告接入后的广告回调检查。
